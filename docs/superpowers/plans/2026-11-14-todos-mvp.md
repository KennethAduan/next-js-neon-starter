# Todos MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a shared team todo list (create, read, update title, toggle completed, delete) behind Better Auth on this starter.

**Architecture:** One `features/todos/` feature. Prisma `Todo` on Neon. Server Component reads the list. Mutations use `authActionClient` + Zod. Shared list: any signed-in user may CRUD any row. No R2, no data-table API for MVP.

**Tech Stack:** Next.js 16.3.1, Bun, Prisma, Neon, Better Auth, Zod, next-safe-action, TanStack Form, shadcn `field` helpers, Jotai only if UI needs shared client state (prefer local state first).

**Spec:** `docs/PROJECT_DOCS.md`

## Global Constraints

- Locked stack: `docs/TECHNOLOGY_STACK.md` — do not swap Neon/Prisma/Better Auth/R2/Zod.
- Feature layout matches `features/auth/` (`pages/`, `actions/`, `components/`, `schema/`, `todos.docs.md`).
- Client HTTP to `ROUTES.API_*` uses `apiClient`; MVP todos do **not** add API list routes.
- Forms: `components/ui/field.tsx` + `components/forms/*` + TanStack Form — no alternate form libs.
- After code changes: `bun run lint`, then `bun run doctor` and `bun run fallow` (fix issues).
- No Firebase. No per-user ownership gates until product changes.
- Commits only when the human asks.

```ts
import { prisma } from "@/lib/prisma"

export async function listTodos() {
  return prisma.todo.findMany({
    orderBy: { createdAt: "desc" },
    select: {
      id: true,
      title: true,
      completed: true,
      createdAt: true,
      updatedAt: true,
      createdById: true,
    },
  })
}

export type TodoListItem = Awaited<ReturnType<typeof listTodos>>[number]
```

- [ ] **3.2** Create `features/todos/actions/todo.action.ts`:

```ts
"use server"

import { ActionError, authActionClient } from "@/lib/safe.action"
import { prisma } from "@/lib/prisma"
import { revalidatePath } from "next/cache"
import {
  CreateTodoSchema,
  TodoIdSchema,
  UpdateTodoTitleSchema,
} from "@/features/todos/schema/todo.schema"
import { ROUTES } from "@/constants/app.routes"

const ACTION_NAME = {
  CREATE: "createTodo",
  UPDATE_TITLE: "updateTodoTitle",
  TOGGLE: "toggleTodoCompleted",
  DELETE: "deleteTodo",
} as const

function revalidateTodos() {
  revalidatePath(ROUTES.HOME)
}

export const createTodoAction = authActionClient
  .metadata({ actionName: ACTION_NAME.CREATE })
  .inputSchema(CreateTodoSchema)
  .action(async ({ parsedInput, ctx }) => {
    const userId = ctx.session?.user.id
    if (!userId) {
      throw new ActionError("Unauthorized")
    }

    const todo = await prisma.todo.create({
      data: {
        title: parsedInput.title,
        createdById: userId,
      },
      select: { id: true },
    })

    revalidateTodos()
    return { success: true as const, id: todo.id }
  })

export const updateTodoTitleAction = authActionClient
  .metadata({ actionName: ACTION_NAME.UPDATE_TITLE })
  .inputSchema(UpdateTodoTitleSchema)
  .action(async ({ parsedInput, ctx }) => {
    if (!ctx.session?.user.id) {
      throw new ActionError("Unauthorized")
    }

    await prisma.todo.update({
      where: { id: parsedInput.id },
      data: { title: parsedInput.title },
    })

    revalidateTodos()
    return { success: true as const }
  })

export const toggleTodoCompletedAction = authActionClient
  .metadata({ actionName: ACTION_NAME.TOGGLE })
  .inputSchema(TodoIdSchema)
  .action(async ({ parsedInput, ctx }) => {
    if (!ctx.session?.user.id) {
      throw new ActionError("Unauthorized")
    }

    const existing = await prisma.todo.findUnique({
      where: { id: parsedInput.id },
      select: { completed: true },
    })
    if (!existing) {
      throw new ActionError("Todo not found")
    }

    await prisma.todo.update({
      where: { id: parsedInput.id },
      data: { completed: !existing.completed },
    })

    revalidateTodos()
    return { success: true as const }
  })

export const deleteTodoAction = authActionClient
  .metadata({ actionName: ACTION_NAME.DELETE })
  .inputSchema(TodoIdSchema)
  .action(async ({ parsedInput, ctx }) => {
    if (!ctx.session?.user.id) {
      throw new ActionError("Unauthorized")
    }

    await prisma.todo.delete({ where: { id: parsedInput.id } })
    revalidateTodos()
    return { success: true as const }
  })
```

- [ ] **3.3** `bun run typecheck` — expect pass.
